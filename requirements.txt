# ── Core ML
# IMPORTANT (learned the hard way while building this project): a plain
# `pip install torch` on PyPI resolves to a CUDA-enabled build that will
# fail to even `import torch` on a machine without a matching NVIDIA/CUDA
# setup, because it silently expects a long list of nvidia-*-cuXX packages
# to already be installed alongside it.
#
#   - If you have an NVIDIA GPU + CUDA installed: `pip install -r requirements.txt`
#     as-is is fine.
#   - If you're on CPU only (no NVIDIA GPU - the common case for a laptop):
#     install torch/torchvision from PyTorch's own CPU index FIRST, then
#     install the rest of this file:
#       pip install torch==2.14.0 torchvision==0.29.0 --index-url https://download.pytorch.org/whl/cpu
#       pip install -r requirements.txt
torch==2.14.0
torchvision==0.29.0
